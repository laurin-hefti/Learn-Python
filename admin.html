💡 How it works

This tool helps you build content and exports it as JSON. To add it to your website:

  1. Choose Quiz, Theory or Markdown Theory below.
  2. Build your content (a quiz needs a unique ID, a theory topic needs an ID too).
  3. Click "🧩 Merge & Download" — it reads the existing data/quizzes.json (or data/theory.json), appends your new item, and downloads the complete updated file.
  4. Replace the file in the data/ folder with the downloaded one (same name).

Note: merging requires the site to be served over HTTP (e.g. localhost:8000), not opened as a local file://.

Markdown topics are saved to their own file (data/theory-md.json), so they never overwrite topics made with the Theory Builder above. To keep the two sets collision-free, an ID that already exists in data/theory.json or data/theory-md.json is rejected.

🗑️ Manage & Delete

Remove an existing quiz or theory topic from the data files. Each deletion updates a preview below — when you're done, click the matching Download button to get the new file and replace it in the data/ folder. A quiz and theory topic with the same ID are linked — delete them separately if you want both gone.
